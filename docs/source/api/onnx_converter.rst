==================
ONNX Converter
==================

.. currentmodule:: iguanas.onnx_converter

Export fitted Iguanas rule strings to a self-contained ONNX binary
classifier that can be served by any ONNX-compatible runtime
(e.g. ``onnxruntime``, ONNX.js, Triton, Azure ML, etc.).
